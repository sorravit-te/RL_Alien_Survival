# Custom Station Maps (Tiled) — MVP

This feature supports drawing your own **top-down geometry** in [Tiled](https://www.mapeditor.org/) and playing it in the existing Pygame first-person raycaster. It is **not** a 3D room editor and does not yet add doors, prop meshes, or floor/ceiling texture casting.

## Open and edit

1. Open `maps/station_demo.tmj` in Tiled.
2. Keep the map **finite / orthogonal / 32 × 32 square tiles** (you may change map width and height).
3. Select object layer **Walls**. Draw *axis-aligned rectangles* snapped to the 32-pixel grid. Each rectangle is solid. Give a wall the custom string property `material` set to `wall`, `lab`, or `crew`.
4. Select object layer **Entities**. Place *point objects* with the exact names: `survivor_spawn`, `alien_spawn`, `waypoint`, `keycard`, `exit`. Points must lie on walkable floor. Multiple `survivor_spawn` and `waypoint` are allowed; just one `alien_spawn`. Alien spawn can have float property `yaw_degrees`.
5. Save as `.tmj`. Use unique object IDs (Tiled maintains these). Keep passage widths wide enough for collision clearance and validate navigation and spawn separation in-game.

The material string is *visual data only*. Collision and AI navigation still use `WorldMap.rows` generated by the wall geometry. This avoids leaking artwork concerns into RL or modifying the training action contract.

## Play

From repository root with its Python environment active:

```powershell
python -m app.play --map maps/station_demo.tmj
```

Existing default gameplay without `--map` remains unchanged.

## Assign purchased Stradex texture files locally

The existing `tools.prepare_assets` workflow prepares `wall1.png` and three additional textures locally. The raycaster defaults to `assets/stradex/prepared/wall1.png`.

To render different wall materials, create `configs/materials.local.json` **on your own machine**:

```json
{
  "wall": "../assets/stradex/prepared/wall1.png",
  "lab": "../assets/stradex/prepared/wall1.png",
  "crew": "../assets/stradex/prepared/wall1.png"
}
```

The paths above are examples: resolve each path **relative to the configuration file**, and replace them with files you are licensed to use. Since `configs/` is one directory below the repository root, local assets in `assets/` are referenced using `../assets/`.

Launch:

```powershell
python -m app.play --map maps/station_demo.tmj --materials configs/materials.local.json
```

Materials not in the JSON use the existing wall texture. Do **not** commit purchased Stradex originals, prepared derivatives, or local material-path files; the public/shared repository must not redistribute these assets. Material files are deliberately excluded through `.gitignore`.

## Limitations / next iteration

* MVP supports **wall materials** only; floor and ceiling are still flat colors.
* The example uses simple rectangular geometry. Visual props, real door behaviors, animated fixtures, floor/ceiling textures, and directional wall faces require additional work.
* A* paths, spawn clearance, waypoints, map connection and reachable keycard/exit should be tested after any layout change.
* Benchmark FPS / frame-time on the Acer notebook before increasing internal resolution or adding expensive floor casting.

Run tests locally:

```powershell
python -m pytest tests/test_map_loader.py tests/test_core.py tests/test_rl.py -q
```
